What's New

  • Block button options

    Pressing the block button now opens a menu that lets you easily block jobs by keyword, company, or job

    The block button action can be set to "Ask", "Block company", or "Block job" by going to the Hide n' Seek popup > Settings > Block button action

  • Block specific jobs

    You can now easily block specific jobs. For the purposes of blocking, a job is defined as {Company Name}: {Job Title}, which is how it will be saved in your blocked jobs list.

  • Accessibility improvements

    The interface has been updated to enhance accessibility, especially keyboard accessibility.
